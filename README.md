## How I learn

I practise identifying the problem, checking device settings, making a targeted change and testing the result.

One recent example: an outside website was unreachable because the ISP-facing router interface was marked as NAT inside. I corrected it to NAT outside, tested website access and checked the translation table.

These projects are learning labs built in Cisco Packet Tracer.
